
# Лабораторная работа 5 - Agile и Scrum

Веб-приложение для управления фитнес-центром. Пользователи могут просматривать расписание тренировок, записываться на занятия, управлять своим абонементом и отслеживать историю посещений. Администраторы управляют тренерами, тренировками и абонементами через админ-панель.

## Sprint Review

### Задачи, закрытые в спринте:
- Создать главную страницу фитнес-центра - разработана и реализована главная страница приложения с информацией о зале, тренерах и контактами. Пользователи могут видеть все основные разделы фитнес-центра
- Настроить форму обратной связи - создана система обратной связи. Пользователи могут отправлять сообщения администрации, все данные сохраняются в базе данных

### Что было доставлено по итогу спринта:
- Рабочая главная страница фитнес-центра с адаптивным дизайном
- Функционал обратной связи с валидацией полей
- Базовый интерфейс приложения готов к использованию
- Пользователи могут ознакомиться с информацией о фитнес-центре и связаться с администрацией

### Задачи, не завершённые в спринте:
- Реализовать страницу расписания тренировок - в процессе разработки. Готов макет календаря, осталось подключить данные из базы и реализовать фильтрацию
- Создать систему регистрации клиентов - в процессе. Реализована форма регистрации, осталось добавить валидацию и интеграцию с email-рассылкой
- Реализовать запись на тренировки - Не начата. Перенесена на следующий спринт из-за нехватки времени и необходимости завершения страницы расписания

## Sprint Retrospective

### Что прошло хорошо:
- Успешно создана главная страница
- Быстро реализована форма обратной связи с полноценной валидацией


### Что пошло не так:
- Серьезно недооценена сложность системы регистрации клиентов (8 story points оказалось мало)
- Задержались с интеграцией календаря на странице расписания тренировок
- Возникли проблемы с правильным назначением меток в Issues
